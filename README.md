## ✨ 当前重点：Data Analysis Agent

**Data Analysis Agent** 是我目前重点构建的项目。

目标是让用户不需要写 SQL，也能够直接通过自然语言分析自己的业务数据：

```text
用户问题
   ↓
意图识别
   ↓
SQL 生成
   ↓
数据执行
   ↓
结果分析
   ↓
异常诊断
   ↓
数据可视化
   ↓
分析报告
```

目前支持：

- 📁 Excel / CSV 文件上传
- 🗄️ MySQL / PostgreSQL / SQLite 数据源
- 💬 自然语言生成 SQL
- 🧠 LangGraph Agent Workflow
- 🧮 派生指标与跨列聚合
- 🔍 异常诊断与原因分析
- 📈 ECharts 自动可视化
- 📝 Markdown 分析报告
- 🔄 多轮上下文对话
- 🕒 自然语言时间理解
- 🤖 DeepSeek / Ollama / OpenAI-compatible LLM
